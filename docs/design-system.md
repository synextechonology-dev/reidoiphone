# Rei do iPhone · design system (como está na prévia)

## Cores
| Token | Escuro (padrão) | Claro | Uso |
|---|---|---|---|
| --bg | #000000 | #F5F5F7 | fundo |
| --bg-2 | #0A0A0B | #FFFFFF | seções alternadas |
| --surface | #111113 | #FFFFFF | cards |
| --surface-2 | #1C1C1E | #EEEEF1 | campos, foto do card |
| --line / --line-2 | rgba(255,255,255,.10) / .18 | #E3E3E8 / #CFCFD6 | bordas |
| --text / --text-2 | #F5F5F7 / #A1A1A6 | #0B0B0C / #5F5F65 | texto |
| --gold | #DFB35A | #DFB35A | botão (texto #0B0B0C), destaque |
| --gold-hover / --gold-press | #E7C878 / #B88742 | igual | estados do botão |
| --gold-ink | #DFB35A | #8A6420 | dourado em texto |
| --ok / --warn / --err | #3DD68C / #FFB547 / #FF6B6B | #1A7A43 / #8F5600 / #C62828 | bateria, avisos |
Hero, comparador e abertura são sempre escuros. Proporção: ~60% preto, ~35% claro, até 5% dourado.

## Fontes
- Geist 600/700: só o H1 do hero (linha 1 em degradê branco→titânio, linha 2 "é o Rei" em dourado com brilho)
- Outfit 500/600: títulos, botões, chips
- Inter 400–700: corpo
- IBM Plex Mono 400/500: preços, GB, bateria, ficha técnica

## Forma
Botões em pílula (52 px; 44 px no card) · campos 12 px · cards 22 px · foto no card 16 px · seção do comparador 28 px · sombra só no hover · cantoneiras de 16 px em volta da foto do aparelho.

O histórico de decisões (referências, troca do laranja pelo dourado do logo) está no Projeto "Synex - dev web", em claude/rei-do-iphone-design-system.md.
